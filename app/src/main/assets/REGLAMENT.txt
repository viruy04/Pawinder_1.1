2. ПОСТАНОВКА ЗАДАЧ
Все основные задачи создаются через GitHub Issues.
Каждая задача должна содержать:
— заголовок
— краткое описание
— исполнителя (Assignee)
— метку (bug / feature / task / docs)

3. ВЕТВЛЕНИЕ
Главная ветка: `master`.
Для каждого участника используется отдельная ветка, названная по фамилии.
Прямой push в `master` запрещён.

4. PULL REQUEST И РЕВЬЮ
Изменения попадают в `master` через Pull Request.
Правила:
— PR создаётся из рабочей ветки в `master`
— требуется минимум 1 approve от другого участника (от codeowner)
— перед merge изменения должны быть проверены

5. КОММИТЫ
Коммиты должны содержать краткое описание выполненной работы.

6. СТРУКТУРА ПРОЕКТА
`/app/src/main/java` — Java-код приложения
`/app/src/main/res/layout` — XML-разметка
`/app/src/main/res/drawable` — изображения и графические ресурсы
`/app/src/main/res/values` — цвета, строки и другие ресурсы
`/.github` — настройки GitHub
`REGLAMENT.txt` — регламент проекта
`README.md` — описание проекта
