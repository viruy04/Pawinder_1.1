# CR-001: Асинхронная предзагрузка URL-адресов карточек

**Автор:** Казакова А. Ю.  
**Дата:** 17.11.2026

## Описание изменения

Модуль `FeedLogic` должен запускать фоновый поток (через `ExecutorService`) для предварительной загрузки URL-адресов следующих 3 карточек животных из списка, чтобы ускорить их отображение при прокрутке ленты.

## Обоснование

Текущая реализация определяет URL фотографии только в момент отображения карточки в `FeedAdapter`. При быстрой прокрутке это может вызывать задержки. Предзагрузка URL позволит подготовить данные заранее.

## Требования к реализации

1. `FeedLogic` создаёт `ExecutorService` с фиксированным пулом потоков (размер 2).
2. Метод `prefetchUrls(List<Pet> pets, int startIndex)` запускает фоновые задачи для обработки URL следующих 3 карточек.
3. Каждая задача вызывает `resolvePhotoUrl` и сохраняет результат в кэш (мапа `Map<Integer, String>`).
4. При прерывании потока (`InterruptedException`) задача корректно завершается, освобождая ресурсы.
5. При завершении работы `FeedLogic` (например, при закрытии экрана) `ExecutorService` должен быть остановлен через `shutdown()`.

## Поведение при отказах

- **Ошибка получения ресурса:** если `ExecutorService` не может создать поток (мало памяти), задача не запускается, ошибка логируется.
- **Ошибка во время работы:** если `resolvePhotoUrl` выбрасывает исключение, задача перехватывает его, URL не сохраняется, поток продолжает работу.
- **Таймаут:** не применяется, так как операция локальная и быстрая.
- **Ранний выход:** при отмене задачи через `Future.cancel(true)` поток прерывается, ресурс освобождается.

## Влияние на системные границы

Добавляется новый ресурс: **пул потоков выполнения**. `FeedLogic` становится владельцем этого ресурса и отвечает за его освобождение.
