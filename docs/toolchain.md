# Инструментальный контур проекта Pawinder

## 1. Назначение

Документ описывает инструменты сборки, тестирования и диагностики Android-клиента Pawinder, а также способы воспроизведения основных проверок.

Связанное архитектурное решение: [ADR-001.md](ADR-001.md).

Инструкция по сборке: [BUILD.md](BUILD.md).

## 2. Инструменты и их назначение

| Позиция | Средство | Назначение и способ подключения | Статус |
|---|---|---|---|
| Сборка | Gradle Wrapper 9.6.0, Android Gradle Plugin 9.4.1, Android SDK | Сборка Android-приложения через Gradle Wrapper | Проверено: Debug и Release собираются |
| Управление зависимостями | Gradle, `gradle/libs.versions.toml`, `app/build.gradle.kts` | Объявление библиотек и версий, разрешение зависимостей при сборке | Конфигурация присутствует |
| Модульное тестирование | JUnit 4.13.2 | Автоматическая проверка отдельных компонентов приложения | Проверено: `testDebugUnitTest` завершилась успешно |
| Инструментальное тестирование | AndroidX Test JUnit 1.3.0, Espresso Core 3.7.0 | Проверка приложения на Android-устройстве или эмуляторе | Наличие зависимостей не подтверждает выполнение инструментальных тестов |
| Статический анализ | Android Lint, инспекции Android Studio | Поиск потенциальных ошибок без запуска приложения | Отдельный запуск и результат требуют подтверждения |
| Динамическая диагностика | Android Studio Debugger, Logcat | Проверка запуска приложения, параметров сборки и диагностических сообщений | Проверено: запуск Release и вывод диагностических сообщений в Logcat |
| Профилирование | Android Studio Profiler | Анализ использования памяти и ресурсов во время выполнения | Запланировано; результаты профилирования не зафиксированы |
| Непрерывная интеграция | GitHub Actions | Автоматическая сборка, запуск модульных тестов и проверка некорректного адреса сервера | По результатам CI, сообщённым при проверке проекта, проверки прошли успешно; ссылка на запуск фиксируется в отчёте |

## 3. Параметры сборки

- Android Gradle Plugin: `9.4.1`.
- Gradle Wrapper: `9.6.0`.
- Требуемая версия JVM по критериям Gradle: `25`.
- Совместимость исходного кода: Java `11`.
- `compileSdk`: `37`.
- `targetSdk`: `37`.
- `minSdk`: `24`.
- `versionCode`: `1`.
- `versionName`: `1.0`.
- `BuildConfig` используется для передачи параметров сборки в приложение.
- Адрес сервера задаётся параметром `pawinder.serverBaseUrl` и проверяется при конфигурации сборки.

## 4. Маршрут воспроизведения

Все команды ниже выполняются из корневого каталога проекта в PowerShell.

### 4.1. Сборка

Сборка отладочного варианта:

```powershell
.\gradlew.bat :app:assembleDebug
```

Сборка варианта Release:

```powershell
.\gradlew.bat :app:assembleRelease
```

### 4.2. Модульные тесты

Запуск модульных тестов:

```powershell
.\gradlew.bat :app:testDebugUnitTest
```

Успешное выполнение подтверждается сообщением `BUILD SUCCESSFUL`.

### 4.3. Проверка параметра сервера

Для проверки отклонения некорректного адреса выполните:

```powershell
.\gradlew.bat "-Ppawinder.serverBaseUrl=ftp://bad/" :app:assembleDebug
```

Ожидаемый результат — завершение сборки с ошибкой и сообщением:

```text
Invalid pawinder.serverBaseUrl: expected an HTTP(S) URL with a trailing slash
```

Эта проверка подтверждает, что параметр адреса сервера проверяется до формирования APK.

### 4.4. Установка и диагностика

Проверить подключённые устройства:

```powershell
adb devices
```

Установить отладочную сборку:

```powershell
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

Запустить приложение:

```powershell
adb shell monkey -p com.example.pawinder_11 1
```

Посмотреть диагностические сообщения:

```powershell
adb logcat -d -s PawinderApp:I
```

В проверенной Release-сборке журнал содержал сообщение о запуске приложения, адрес сервера и строку версии `1.0+676b41ce (release)`.

## 5. Непрерывная интеграция

В проекте используется GitHub Actions. Workflow предназначен для автоматизации сборки Android-клиента, запуска модульных тестов и проверки отклонения некорректного параметра адреса сервера.

Результат CI следует подтверждать ссылкой на соответствующий запуск GitHub Actions. Автоматическая проверка не заменяет ручную проверку установки и запуска приложения на устройстве.

## 6. Ограничения

Наличие зависимости или инструмента в конфигурации проекта само по себе не подтверждает выполнение соответствующей проверки.

Отдельный успешный запуск Android Lint, инструментальных тестов и Android Studio Profiler в данном документе не заявляется без зафиксированных результатов.

Документ описывает инструментальный контур Android-клиента Pawinder и не подтверждает полноценную работу всех функций приложения или развёртывание серверной части.
