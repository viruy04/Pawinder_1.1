# Pawinder – инструкция по сборке Android-клиента

## 1. Требования к окружению

Проверенная локальная сборка выполнялась в следующем окружении:

- Операционная система: Windows 11.
- JDK: 25.0.1.
- Gradle: 9.6.0 (Gradle Wrapper).
- Android Gradle Plugin: 9.4.1.
- Android SDK: `compileSdk 37`, `targetSdk 37`, `minSdk 24`.
- Совместимость исходного кода: Java 11.
- Android SDK Build-Tools: 36.1.0.

Для сборки необходимы JDK, Android SDK и доступ к репозиториям зависимостей Google Maven и Maven Central.

## 2. Получение исходного кода

Клонируйте репозиторий проекта и перейдите в его каталог. Для проверки исходной версии приложения можно использовать коммит:

`676b41cec2081affe21139ce1156b83d451dbbe1`

```powershell
git clone https://github.com/viruy04/Pawinder_1.1.git
cd Pawinder_1.1
git checkout 676b41cec2081affe21139ce1156b83d451dbbe1
```

Проверьте состояние рабочей копии:

```powershell
git status --short
```

Для воспроизводимой проверки желательно использовать чистую рабочую копию без незакоммиченных изменений.

## 3. Настройка адреса сервера

Адрес сервера задаётся параметром Gradle `pawinder.serverBaseUrl`. URL должен использовать протокол HTTP или HTTPS и заканчиваться символом `/`.

Для сборки с адресом сервера, заданным по умолчанию в проекте, выполните:

```powershell
.\gradlew.bat :app:assembleDebug
```

Чтобы указать другой адрес сервера, передайте параметр при запуске Gradle:

```powershell
.\gradlew.bat "-Ppawinder.serverBaseUrl=https://example.com/" :app:assembleDebug
```

Замените `example.com` адресом используемого сервера.

Некорректное значение параметра отклоняется во время конфигурации сборки. Например, адрес `ftp://bad/` приводит к сообщению:

```text
Invalid pawinder.serverBaseUrl: expected an HTTP(S) URL with a trailing slash
```

## 4. Сборка приложения

### 4.1. Отладочная сборка

Для сборки Debug-варианта выполните:

```powershell
.\gradlew.bat :app:assembleDebug
```

Для запуска модульных тестов выполните:

```powershell
.\gradlew.bat :app:testDebugUnitTest
```

### 4.2. Release-сборка

Для сборки Release-варианта выполните:

```powershell
.\gradlew.bat :app:assembleRelease
```

Release-вариант использует оптимизацию R8. Полученный APK не подписан и не предназначен для непосредственной установки до выполнения необходимых этапов подготовки и подписания.

## 5. Результаты сборки

После успешной сборки файлы APK располагаются по следующим путям:

| Вариант | Путь |
|---|---|
| Debug | `app/build/outputs/apk/debug/app-debug.apk` |
| Release без подписи | `app/build/outputs/apk/release/app-release-unsigned.apk` |

Для учебной установки Release APK можно выровнять и подписать тестовым ключом. Такой ключ не предназначен для публикации приложения.

## 6. Установка и запуск на Android-устройстве

Подключите Android-устройство с включённой отладкой по USB и проверьте его обнаружение:

```powershell
adb devices
```

Установите Debug APK:

```powershell
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

Запустите приложение:

```powershell
adb shell monkey -p com.example.pawinder_11 1
```

Для просмотра диагностических сообщений используйте:

```powershell
adb logcat -d -s PawinderApp:I
```

При запуске приложение записывает сообщение о старте, адрес сервера и строку версии, содержащую версию приложения, сокращённый SHA коммита и тип сборки.

Пример строки версии для проверенной Release-сборки:

```text
App version: 1.0+676b41ce (release)
```

Фактическое значение SHA зависит от коммита, из которого выполнена сборка.

## 7. Автоматическая проверка

GitHub Actions используется для автоматизации проверки Android-клиента. Workflow выполняет сборку Debug-варианта, запуск модульных тестов и проверку отклонения некорректного значения `pawinder.serverBaseUrl`.

Успешное завершение CI подтверждает выполнение предусмотренных автоматических проверок, но не заменяет ручную проверку установки и запуска приложения на Android-устройстве.

## 8. Ограничения

Для воспроизведения сборки необходимы установленные JDK и Android SDK, а также доступ к репозиториям зависимостей.

Настоящая инструкция описывает сборку Android-клиента Pawinder. Она не является инструкцией по развёртыванию сервера Spring Boot.

Наличие пользовательского интерфейса регистрации, авторизации и избранного само по себе не подтверждает полноценную работу соответствующей бизнес-логики.
