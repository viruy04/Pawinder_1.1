# ADR-001. Выбор стека проекта Pawinder

**Автор:** Казакова А. Ю.  

## 1. Контекст

Pawinder – мобильное приложение для Android, предназначенное для подбора животных из приютов с помощью ленты карточек. Проект включает мобильный клиент, серверную часть и базу данных MySQL.

Разработка ведётся на ноутбуках под управлением Windows 11. Запуск и проверка мобильного приложения выполняются на устройстве с Android или эмуляторе.

Основные ограничения проекта:
- учебные сроки разработки;
- команда из двух студентов;
- использование бесплатных средств разработки;
- необходимость обеспечить взаимодействие мобильного клиента с серверной частью.

## 2. Решение

Для разработки проекта выбран следующий стек технологий.

**Язык программирования:** Java для мобильного клиента и серверной части.

**Мобильный клиент:**
- Android Studio – среда разработки;
- Android SDK – инструменты разработки Android-приложения;
- Gradle – система сборки;
- Retrofit и Gson – взаимодействие с REST API и обработка JSON;
- Glide – загрузка и отображение изображений.

**Серверная часть:**
- Spring Boot – разработка серверного приложения.

**База данных:**
- MySQL – хранение данных;
- MySQL Workbench – управление базой данных.

Интерфейс Android-приложения работает в главном потоке. Сетевые запросы выполняются асинхронно, чтобы не блокировать интерфейс. Сервер принимает и обрабатывает запросы от мобильного клиента.

## 3. Причины выбора и рассмотренные альтернативы

При выборе стека учитывались навыки участников команды, учебные сроки и необходимость обеспечить взаимодействие мобильного приложения с сервером.

Первоначально рассматривался Kotlin для разработки Android-клиента. В качестве альтернативы была выбрана Java, поскольку она используется как в мобильном клиенте, так и в серверной части на Spring Boot.

Использование одного языка программирования для обеих частей проекта позволяет применять общие знания Java и упрощает работу команды с кодом.

## 4. Последствия принятого решения

**Преимущества:**
- использование Java в клиентской и серверной частях проекта;
- применение Android Studio и MySQL Workbench, знакомых участникам команды;
- использование бесплатных инструментов разработки;
- возможность разделять мобильный клиент, серверную часть и базу данных.

**Ограничения и обязанности:**
- для сборки проекта необходимо настроить JDK, Android Studio, Android SDK и Gradle;
- для работы серверной части и базы данных требуется соответствующее окружение;
- для проверки мобильного приложения необходим телефон с Android или эмулятор;
- адрес сервера и параметры подключения к базе данных должны задаваться через конфигурацию, а не жёстко прописываться в исходном коде;
- необходимо отдельно обеспечивать запуск и проверку мобильного клиента и серверной части.

## 5. Итог

Выбранный стек соответствует учебным ограничениям проекта Pawinder и позволяет разрабатывать Android-клиент, серверную часть и систему хранения данных с использованием доступных инструментов.
