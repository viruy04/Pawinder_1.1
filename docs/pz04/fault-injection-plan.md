# План внедрения отказов — ПЗ04

## Цель
Проверить реакцию ленты Pawinder на смоделированные ошибки загрузки карточек животных в соответствии с CR-001.

## Сценарий FI-01 — имитация HTTP 500

**Воздействие:** запуск приложения с тестовым параметром `pz04_fault_http500=true`.

**Ожидаемый результат:**
- приложение не завершается аварийно;
- индикатор загрузки скрывается;
- пользователю показывается сообщение «Не удалось загрузить ленту»;
- некорректные данные не добавляются в список карточек.

**Фактический результат:** приложение осталось запущенным, отображено сообщение «Не удалось загрузить ленту».

**Статус:** PASS.

## Сценарий FI-02 — имитация сетевой ошибки

**Воздействие:** запуск приложения с тестовым параметром `pz04_fault_network=true`.

**Ожидаемый результат:**
- приложение не завершается аварийно;
- индикатор загрузки скрывается;
- пользователю показывается сообщение об ошибке сети;
- существующие карточки не заменяются некорректными данными.

**Фактический результат:** приложение осталось запущенным, отображено сообщение «Ошибка сети: тестовый сетевой сбой».

**Статус:** PASS.

## Условия проведения
Проверки выполнены на подключённом Android-устройстве. Отказы искусственно смоделированы через параметры запуска Activity. Проверки подтверждают реакцию пользовательского интерфейса на эти сценарии, но не являются проверкой настоящего ответа HTTP 500 или реального сетевого сбоя.

## Ограничения
В рамках этих двух сценариев отдельно не проверялись фактическое освобождение ресурсов, поведение при исключении во время обработки ответа и реальная реакция Retrofit на сетевой сбой. Эти проверки требуют дополнительных испытаний.
