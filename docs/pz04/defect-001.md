# DEF-001 — потеря прежних данных при ошибке обработки списка ленты

**Связанный запрос на изменение:** CR-001  
**Компонент:** `FeedLogic.replaceItemsSafely()` и `FeedFragment.onResponse()`  
**Тип дефекта:** обработка исключений  
**Серьёзность:** средняя  
**Приоритет:** высокий

## Описание

При замене списка карточек прежние данные могли быть удалены до завершения обработки нового списка. Если во время чтения элементов нового списка возникало исключение, прежние данные терялись, а ошибка не обрабатывалась в рамках операции замены списка.

## Ожидаемое поведение

При ошибке обработки нового списка прежние данные должны сохраняться. Исключение должно обрабатываться без аварийного завершения приложения, а пользователь должен получать сообщение об ошибке обработки данных.

## Воспроизведение

В регрессионном тесте `tcFd19_processingException_keepsPreviousItems` используется список, который выбрасывает `RuntimeException` при чтении элемента. До исправления тест завершается ошибкой, поскольку прежний список очищается. После исправления тест проходит: метод возвращает `false`, а прежние данные сохраняются.

## Причина

Очистка целевого списка выполнялась до того, как обработка исходного списка гарантированно завершалась успешно.

## Исправление

Перед изменением целевого списка создаётся копия исходного списка. Если обработка исходного списка завершается исключением, метод возвращает `false`, не изменяя прежние данные. `FeedFragment` обрабатывает неуспешную замену списка и показывает сообщение об ошибке.

**Статус:** FIXED — исправление реализовано, регрессионный тест пройден после исправления.
