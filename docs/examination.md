# Протокол обследования Pawinder

| Поле                           | Содержание                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Дата и участники**           | 09.10.2026. Участники: команда разработки Pawinder из двух человек. Собеседник: пользователь, заинтересованный в том, чтобы взять животное из приюта. Режим: учебный заказчик.                                                                                                                                                                                                                                            |
| **Текущий процесс**            | Пользователь ищет животных на сайтах приютов и в социальных сетях. Он просматривает фотографии и описания, сравнивает животных и самостоятельно ищет контакты приюта, чтобы узнать подробности о понравившемся питомце.                                                                                                                                                                                                            |
| **Подтверждённые потребности** | В рамках учебного сценария определены следующие потребности: удобный просмотр карточек животных, возможность отмечать понравившихся питомцев, доступ к подробной информации и контактам приюта. Эти потребности подтверждены реальным интервью.                                                                                                                                                                            |
| **Примеры данных и ситуаций**  | Пример карточки: собака, кличка Рекс, возраст 2 года, фотография и краткое описание. Данные о животных поступают из подключённого API через серверную часть Spring Boot. Пример ситуации: пользователь просматривает карточку и свайпает вправо, если животное ему понравилось. Пример является синтетическим.                                                                                                                     |
| **Ограничения**                | Команда состоит из двух человек. Разработка ведётся на Windows 11 с использованием Android Studio. Клиент написан на Java, серверная часть — на Spring Boot. Получение карточек зависит от доступности серверов с базой данных и API. Сроки ограничены рамками семестрового проекта. |
| **Предположения команды**      | Карточки и свайпы могут упростить просмотр животных. Избранное позволит вернуться к понравившимся питомцам. Контактная информация приюта поможет пользователю перейти от выбора к знакомству с животным. Необходимость фильтров пока не подтверждена.                                                                                                                                                  |
| **Открытые вопросы**           | Какие характеристики животного наиболее важны при выборе? Нужны ли фильтры по возрасту и виду животного? Должны ли лайки сохраняться после перезапуска приложения? Нужна ли возможность отменить свайп? Какая информация о приюте необходима пользователю? Ответственные за уточнение: участники команды Pawinder.                                                                                                                 |
| **Решения**                    | Для ближайшей версии выбраны просмотр карточек животных, свайпы, доступ к личному кабинету и избранному, лента со всеми питомцами. Алгоритм персонализированного подбора можно реализовать позднее.                                      |
