# Профиль сложности проекта Pawinder

**Автор:** Казакова А. Ю.

## 1. Объект и вопрос исследования

**Объект:** модуль логики ленты Android-клиента.

**Вопрос:** можно ли заменить реализацию обработки URL фотографий, проверки ответа сервера и подготовки сетевых ошибок без изменения `FeedAdapter` и `FeedFragment`?

## 2. Критерии готовности

- Контракт явно задаёт три публичные операции.
- Существуют две реализации общего интерфейса.
- Потребители обращаются к реализации через единую точку создания.
- Обе реализации проходят одинаковые тестовые сценарии.
- Сборка Android-клиента завершается успешно.
- Карта модулей отражает фактические зависимости.

## 3. Проверяемые направления сложности

| Направление | Вопрос | Проверка |
|---|---|---|
| Зависимости | Можно ли заменить реализацию без правки потребителей? | Переключение реализации в `FeedLogicProvider` и сборка |
| Корректность | Одинаково ли обрабатываются обычные, граничные и ошибочные входные данные? | Модульные тесты обеих реализаций |
| Сопровождение | Понятны ли ответственность и публичные операции модуля? | Контракт и карта модулей |

## 4. Результат

Профиль считается проверенным после успешной сборки и выполнения тестов обеих реализаций. Выводы должны подтверждаться фактическими результатами запуска команд и кодом проекта.
