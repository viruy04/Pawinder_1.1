## Выбранное изменение

## Как результат проверок влияет на слияние

- Статусная проверка сборки обязательна: красный результат блокирует слияние в `master`.
- Зелёная сборка — необходимое, но не достаточное условие. Для PR, который меняет только документы, сборка не проверяет их содержание, поэтому здесь решающую роль играет review.
- Слияние возможно только после одобрения участником, не являющимся автором PR.

## Ограничения текущих проверок

Сейчас автоматически проверяется только сборка. Тестов, статического анализа и проверок безопасности пока нет; они добавятся по мере появления кода, который можно проверять (например, логика избранного без дублей). Успешная сборка не доказывает корректность поведения.

## Что проверить перед сдачей

- В настройках GitHub включены: запрет прямого push в `master`, обязательный PR, обязательные статусные проверки, обязательное одобрение. Описание в правилах должно совпадать с реальными настройками.
- Триггеры workflow совпадают с описанием в правилах (сейчас там указан запуск при открытии и обновлении PR).
